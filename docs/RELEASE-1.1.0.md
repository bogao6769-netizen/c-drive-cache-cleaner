# C 盘缓存清理器 1.1.0

轻量 Windows 便携工具：先扫描、看明细，再确认清理。

## 新增

- 查看每个分类的文件路径、容量、候选数量和保留原因；可导出全部扫描明细。
- 停止扫描或后续清理；停止不会撤销已经完成的删除。
- 导出 CSV 清理结果，分别记录预计容量、已删除文件容量和磁盘可用空间变化。
- 问题反馈入口、中文反馈模板、贡献与安全说明，MIT 许可证。

## 安全改进

- 检查缓存根目录及祖先目录的链接 / 目录联接。
- 只清理扫描快照；删除前核对文件身份、实际路径与修改时间。
- 在验证过的 Windows 文件句柄上删除，跳过占用、只读、多重硬链接及无权限项目。
- 崩溃转储和错误报告默认不选中；错误和停止不再冒充成功。
- 不再递归删除空目录，不信任任意 TEMP 环境变量覆盖。

## 下载与核验

选择 `CDriveCacheCleaner-v1.1.0-portable.zip` 解压，或直接下载 `CDriveCacheCleaner.exe`。SHA256SUMS.txt 列出本次构建的 SHA-256，可用 `Get-FileHash .\CDriveCacheCleaner.exe -Algorithm SHA256` 对照。

Windows 10/11，.NET Framework 4.x；不需要管理员身份。没有商业代码签名，遇到未知发布者提示时请先核验来源和哈希，不要关闭安全软件。

本机验证：Windows 11 64 位，沙盒安全测试；GitHub Actions 另行在 Windows runner 构建与自检。Windows 10、32 位和不同 DPI 仍需真实设备反馈，不能视作全面兼容认证。

清理不会进入回收站，重要数据请先备份。程序本身不上传数据；报告仅部分脱敏，分享前请人工检查。
